# Digital Opus Engine — working notes

Zero-dependency WebGL2 engine (`engine/src`, built to `dist/opus-engine.js`) plus a no-code browser game editor (`editor/`) that uses only the public `window.Opus` API.

## Where code lives
- Editor source of truth: `editor/src/modules/NN-name.js` (contiguous numbering). `editor/src/01-editor.js` is GENERATED by `node build/build-editor.js`; never edit it directly. `build.js`, the site builders and `tools/dev-server.js` assemble it automatically.
- The boot module (`NN-onboarding.js`) must stay the last module: exported and hosted games boot straight into Play during it, so any module whose state Play uses must come earlier.
- Standalone editor helpers: `editor/src/00-*.js` (the site build ships every `00-*.js`). `00-durable-storage.js` installs the IndexedDB-backed project storage before `editor/index.html` boots the editor. Engine: `engine/src/NN-*.js`.
- Hosted game pages (`dist/engine-site/games`) share content-hashed `opus-engine-runtime.*.js` / `opus-editor-runtime.*.js`; user exports and `dist/games` stay single-file.
- Public example games: `games/<id>.json` (2-space JSON + trailing newline). Keep exactly 28 public games.

## Commands
- Build: `node build/build.js` (engine + editor), then `node build/build-games.js` and `node build/build-engine-site.js` for the public site in `dist/engine-site`.
- Tests: `node tests/run-tests.js` (~2–10 min; builds first). Many tests extract named functions from `editor/src/01-editor.js` by regex into a vm sandbox: when a controller starts calling a new top-level helper or state variable, add it to those tests' extraction lists.
- After adding behavior events, actions, conditions or components, regenerate the creator guide: `node build/build-docs.js --write` (tests compare docs/generated/index.html). New EVENTS entries go at the end of the list.
- Real-game check: `node tools/run-collision-sweep.js dist/engine-site 30 [id,id]` (headless Edge via the Playwright copy referenced in the script).
- Release: `powershell tools/package-hostinger.ps1`, then `node tools/audit-hostinger-upload.js release/<dir>/public_html`.

## Machine quirks
- Windows PowerShell 5.1 only (no pwsh). Rewriting existing files in place can fail with errno -4094: write a temp file and rename, or use the Edit tool. Shell heredocs can eat backslashes.
- The in-app browser pane pauses animation when not visible; use headless Playwright for gameplay checks.

## Rules
- Never commit, push, deploy or touch DNS without the owner's OK. Target host is engine.digitalopusadsolutions.com; never touch games.digitalopusadsolutions.com.
- Prefer verifying in the real built game/editor over component-only tests.
