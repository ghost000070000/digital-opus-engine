# Phase 046 baseline characterization

The required Phase 045 verdict is `PHASE_045_CHARACTER_COLLISION_WALL_SLIDE_READY`. At Phase 046 start, HEAD was `f1dc3516b585ebf5aa868006792c1dc1b9039da9` on `main`; the shared worktree was already dirty (767 status entries) and was preserved. Baseline `node build/build.js` produced 168,984 raw / 43,457 gzip bytes from 22 engine sources. The editor package was 1,971 KB. Baseline integrated tests passed, as did 28/28 public game builds. Phase 045 had 36 focused checks, 1,990 Phase 011–045 checks, and 2,352 integrated checks.

Phase 043's `moveKinematicBody2D` is a deterministic X-then-Y world-delta solver against enabled Static Body 2D objects bearing ordinary Box/Circle Collider 2D shapes. It owns the conservative sweeps, narrow overlap, parent-aware translation callback, and stable object hit IDs. An ordinary Kinematic Body uses only this Static path. Trigger lifecycle runs after Body motion in the editor tick.

Phase 045's `moveCharacter2D` routes only a valid enabled Character component with enabled Kinematic Body and ordinary Box/Circle Collider through the Character path. It gathers one local sparse Tilemap candidate set for the entire requested sweep, resolves X, probes contact, optionally caps world-down wall slide, resolves Y, and probes final grounded/ceiling/walls. The provider reads Phase 034 Full Cell/Custom Rectangle/None geometry from resolved Tile IDs and honors Layer `collisionEnabled` independently of visible/locked. It creates no per-cell Body or scene object. Contact is transient and cleared on Play/Level/component boundaries. The Body velocity is authored intent, not rewritten by response.

Before Phase 046, a Tileset was version 4 and Tile collision metadata had only `mode` plus a normalized `rect` for Custom Rectangle. Scene Static eligibility came from enabled Body type Static; Box world geometry has four stable local-order transformed points, Circle uses the larger XY basis scale. The Phase 045 direct Tile query already handles negative, non-square, rotated, scaled, and mirrored Tilemaps and synthetic `tile:<map>:<layer>:<x>:<y>` IDs. Phase 046 adds top-surface classification without altering the ordinary Kinematic solver.
