# Phase 047 characterization

Phase 047 extends the Phase 043–046 Kinematic Character path without changing the ordinary Body 2D solver or adding a creator-facing triangle collider. Character Collision 2D is v2. Fresh components enable slope and bounded-step handling; migrated v1 components retain both options disabled so existing projects preserve their prior flat/one-way behavior. The component supplies collision and contact state only—not input, gravity, jumping, Dynamic Body behavior, or moving-platform carry.

Static Box top support is extracted from the authored local horizontal edge after the complete world transform, including parent and mirror. Its finite transformed segment, upward normal, and Character-specific maximum angle determine walkability; steep edges remain solid blockers. Tile slopes are authored on Tileset v6 as up-right or up-left triangular solid regions, with optional downward-only one-way tops. Resolved Terrain/Auto-Tile cells use the same tile definition. A sparse Tile query emits ephemeral world geometry and stable synthetic support IDs; no per-cell scene objects or serialized caches are added.

The Character path accepts support-projected horizontal motion on walkable slopes, probes bounded downward continuity, and classifies support as flat or slope with ground normal, angle, and ID. Step-up is atomic: a grounded horizontal blocker can be cleared only when a candidate elevation is within the authored maximum and the destination/head clearance succeeds. Step-down follows only a short supported descent; airborne motion never acquires a distant floor. Rotated scene one-way tops and one-way Tile slope tops accept downward crossings and upward pass-through. Trigger lifecycle still observes resulting Body motion.

Focused Phase 047 checks are 40/40. Deterministic independent audits passed 500,000 surface cases, 250,000 triangle-overlap comparisons, 500,000 slope-movement cases, 500,000 step cases, 200,000 transformed/non-square Tile query comparisons, and a 10,000-cell local-query performance pass. The 10-composition × 2-tier export campaign booted all 20 artifacts in the local browser without console errors. The generated Editable artifact retained a changed 45° Inspector value after local Save, full page reload, and Load Selected. These checks do not by themselves constitute a four-hour endurance or final release verdict; that run began at 2026-09-25T02:51:05.089Z and is tracked separately in `qualification/phase-047/endurance-state.json`.

Known scope boundary: slopes require a walkable Static Box top or a Tileset slope Tile. Circles are obstacles but not walkable slope surfaces. Tile slope geometry is limited to the two 45° triangle directions; arbitrary polygons and curved surfaces remain out of scope. A later controller should request Kinematic motion and consume the read-only contact state, not duplicate this solver.
