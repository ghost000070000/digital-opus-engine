# Showcase asset sources and licensing

The rehabilitation kit is original repository work. Its geometry, rig hierarchies, animation curves, palette, pixel algorithms, and sound waveforms are authored in `tools/showcase-assets.js`. No external models, image downloads, samples, fonts, or music recordings are incorporated in this kit. Generated outputs use the repository's [MIT License](LICENSE), including the existing Digital Opus Engine Authors copyright notice. Retain that notice when distributing the asset sources or substantial portions of the kit; no additional third-party credit is required.

This is a source/provenance record for this kit, not a retroactive license claim over unidentified historical imports. Public classification still depends on the catalog quality gate.

All sixteen files under `assets/showcase/audio/` are synthesized from seeded noise, sine oscillators, amplitude envelopes, and authored note sequences in `tools/showcase-assets.js`. ## Historical assets and public eligibility

The pre-rehabilitation repository contains `tests/fixtures/skinned-bend.gltf`, historical embedded `IronSentry` copies of that diagnostic ribbon, `dogfood-assets/*`, and embedded procedural texture/audio data in several games. These files predate the generator above. The ribbon is a regression fixture and is unsuitable public art regardless of licensing. The rehabilitation replaces its visible uses with original characters. An unused historical asset need not be rendered or promoted merely because it remains in an internal project.

The new kit does not incorporate historical `dogfood-assets` geometry or audio. Where historical textures remain embedded in a project, their original source must be documented or their use replaced with a kit texture before that project is promoted. A generated title-card image does not count as real gameplay screenshot evidence.

## Reproducibility and distribution

- `node tools/showcase-assets.js` writes all 58 model/texture/audio files plus `assets/showcase/manifest.json`.
- `node tools/verify-showcase-assets.js` checks geometry, skin metadata, texture headers, audio levels, and deterministic lookup behavior.
- `node tools/verify-showcase-assets.js --render` also captures real engine asset previews with locally installed Playwright/Sharp and Edge. These are asset-review images, not game screenshots.
- Game JSON embeds only the selected meshes, textures and audio through `install`; no remote asset requests are needed in standalone exports.
- Keep this provenance document and `LICENSE` with any subsequently approved release. This pass does not authorize deployment or a public upload.
