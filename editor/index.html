First-person camera setup (switches controller)
          
          
Sets this level's Player to First-Person with 70° FOV, eye height 0.6, and zero opening yaw/pitch. Other Player settings are kept. Takes effect next Play; Undo restores your setup. An active Camera or Change Camera Action intentionally overrides the live Player view with its own shot.

Forward/reverse throttle drives the craft's facing; Left/Right steer. Boost uses the Jump action (default Space). Higher steering strength turns faster; higher drag slows coasting faster. Stop Play to edit.

          
Handling, boost and ground setup
Movement speed is the normal speed limit. Acceleration and boost acceleration add speed over time; Boost speed kick is an immediate addition. For a faster boost, set its speed limit above normal speed: a lower boost limit deliberately slows the craft during Boost. Boost lasts 0.8 seconds with a fixed 4-second cooldown; collision radius is fixed at 0.55 m. These timings and radius are not changed by these controls. Use positive finite values: saved legacy zero or empty handling values retain their existing fallback behavior, not a disabled effect. Blank edits keep the saved value. Solid meshes are horizontal blockers regardless of height, so keep decorative floors non-solid and use separate solid walls. Terrain/Water supply the hover surface; no wheels, Jump or gravity are added. Visuals, input contexts and the current Camera are preserved.

        

        

          
        

        

          

          
Radius is the existing controller's horizontal clearance, not the visible mesh width. Changes take effect next Play.

          

          

          
          
Fit uses the standing character's unanimated mesh height and visual scale, aligns feet, and enables visual crouch-height following. Clear height to restore legacy physics. Takes effect next Play; it does not replace collision with a skeleton.

          

        

        

          
          
Top-down moves on world XZ: Forward (default W/Up) is −Z, Right (default D/Right) is +X. Turning changes the Player's facing, not the input axes.

          
Ground and camera setup
This controller has no Jump or gravity. Solid meshes block horizontally regardless of height: keep decorative floors non-solid and use separate solid walls, with a clear Spawn Point. Terrain contact can raise the Player; there is no automatic falling or water buoyancy. The current Camera remains unchanged. For a map-north view, use the existing Top-down Camera in the Scene palette; creating it deliberately changes the Active Camera.

        

        
Movement/body and Player Visual edits are undoable. Blank numeric fields in these controls retain saved values; clearing Body Height deliberately restores legacy sizing. Stop Play to edit.

Sequences▾

      

        
Sequence: existing Actions in order, with optional Delays. On Signal → Play Sequence starts one without Script. Add Send Signal steps to notify other Objects after a Wait; choose a named Signal and matching value.

Sprite Sorting Layers▾

      

        
Lower layers draw behind higher layers. Within a layer, lower Order in Layer draws behind. Transform Z remains spatial position.

        

        
        
Default has a reserved stable ID and cannot be renamed or deleted. Layer edits use the existing project-settings non-Undo boundary.

      


      
Collision Layers▾

      

        
Geometry interacts only when both masks accept the other's layer. Maximum 32 layers; Default is reserved.

        

        
        
        

      

      
Parallax Layers▾

      

        
Camera-relative Sprite backgrounds. 1,1 is normal world motion; lower values move more slowly; values above 1 create foreground motion.

        

        
        
Negative and above-1 factors are supported. Deleting a referenced layer requires confirmation and preserves repairable references.
