# Phase 045 characterization

Phase 045 extends the Phase 043 Static/Kinematic Body 2D manager without changing Body v1 or adding Dynamic Body. The first-class Character Collision 2D v1 component is authored through the shared schema/Inspector and is eligible only with an enabled Kinematic Body and ordinary Box/Circle Collider. Missing requirements remain warnings. Ordinary Kinematic Bodies keep Static-only motion.

The canonical `moveCharacter2D` service reuses `moveKinematicBody2D` for each axis. It gathers one conservative swept Tile candidate set, resolves X, reads pre/after-X side/ground contact, optionally clamps downward Y displacement, resolves Y, then probes final contact. The same candidates serve movement and probes. Requested Body velocity remains authored. Contact state is transient, read-only, and cleared on Play boundaries, level changes, deletion, and component removal/disable.

Tilemap v4→v5 migration adds Layer `collisionEnabled: true`. This single participation flag is independent of visible/locked and is preserved by Tilemap serialization/bundles/exports. Phase 038 Chunk Layers remain unchanged. Phase 045 reads resolved Tile IDs, Phase 034 Full Cell/Custom Rectangle/None metadata, and sparse per-Layer indexes directly; no per-cell Body or scene object is created. Rotated-cell world-AABB coverage required a one-cell transformed-footprint expansion before inverse-coordinate enumeration; 100,000 randomized reference comparisons across 20 seeds then matched brute-force AABB candidates.

Focused tests cover component schema/dependencies, migration, Layer toggles, Static and Tile obstacle compatibility, persistent contact, wall slide, frame-rate partition, high-speed Tile anti-tunneling, multi-Collider contact, rotated/scaled/mirrored/non-square geometry, negative coordinates, and Trigger-behind-wall behavior. The 500,000-move deterministic fuzz over 20 seeds completed with 40,246 wall-slide outcomes and no reported penetration/invariant failure. Conservative contended warmed 10,240-cell benchmark: one Character 0.702 ms median / 1.135 ms p95 with 49 coordinate slots; 100 Characters 16.614 ms median / 29.955 ms p95 with 4,900 coordinate slots, versus 10,240 authored cells. The 20-cycle browser campaign, including Editable/Playable runtime execution and save/reload, passed with zero page, console, or network errors. The exact-final 30-minute active soak passed 162,850 moves with 40,713 grounded ticks and 20,356 wall slides; measured counters are in `qualification/phase-045/soak-proof.json`.

The checked-in minimal browser fixture is `qualification/phase-045/phase-045-project.json`. Its generated extended dogfood sibling contains ten objects, a rotated/scaled multilayer map, a parented Character, a Character Prefab, and a 10,240-cell map; project validation reports zero issues. The browser fixture exercises the real parent world→local movement callback as well as Static wall and hidden/locked Tile floor collision.

Remaining deliberate limitations: no input, gravity, jumping, one-way platforms, slopes/steps, moving-platform carry, collision masks/layers, collision events, global contact overlay, or Dynamic Body. Those are separately scoped future seams, not hidden Phase 045 behavior.
