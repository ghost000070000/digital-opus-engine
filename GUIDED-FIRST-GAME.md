# Guided First Game

Target time is 10–20 minutes for a newcomer. Start from the first-run welcome or choose **Help → Restart Tutorial in a Blank Project**.

1. Drag **Cube** from Objects into the viewport.
2. Select it and use **Move**, or edit Position in the Inspector.
3. Choose **Add Component** and add **Health**.
4. Choose **Apply Gameplay Preset** and apply **Collectible**. Its ordinary Behaviors remain visible and editable.
5. Open **Level → Player Controller** and choose how the Player moves. The Player appears when Play begins.
6. Open **UI**, choose **Counter Display**, and add the HUD element.
7. Press **Play**, move into the collectible, then press **Stop**.
8. Name and **Save** the project locally.
9. Open **Project → Import / Export** and choose **Export Playable Game (.html)**.

The checklist updates from the scene and successful actions. **Show me** opens the correct editor surface and highlights the actual control. **Check progress** refreshes the state. The close control pauses the tutorial; Help can resume it later.

No step requires Custom Script, JSON, the browser console, or raw IDs. This is deliberately a 3D first game; World-Space Billboard is not presented as a Sprite.
