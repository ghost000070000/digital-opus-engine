# Phase 046 characterization

Phase 046 extends the Phase 045 Character-specific Static/Tile obstacle path. The ordinary Phase 043 Kinematic Body mover, Trigger semantics, Body v1 roles, and existing solid X→Y response remain unchanged. A singleton `one-way-platform-2d` v1 component has one authored Boolean (`enabled`, default true). It becomes active only with an enabled Static Body 2D and enabled Box Collider 2D. Its local +Y Box edge is the support plane; a same-object Circle is ignored for Character one-way response, while ordinary Kinematic collision retains its prior solid interpretation. The component has no duplicate geometry. A zero-alpha render object is still physical.

Tileset v4→v5 adds `collision.oneWay` to Full Cell and Custom Rectangle Tiles. Old records migrate to false; None canonicalizes to false. Tile Palette editing, previews, duplication, Save/Load, Bundles, and Editable/Playable exports preserve the flag. Character physics reads the resolved Tile ID across Terrain and Auto-Tile cells, and honors each Layer's independent `collisionEnabled` flag even if the Layer is hidden. The direct sparse query keeps ephemeral candidates, not one scene object per cell.

Eligibility is a world-horizontal top edge (rise/run at most 0.01). Mirroring is valid. Unsupported rotated scene Boxes or Tilemaps warn and fall back to ordinary solid collision; they do not become approximate slopes. Each downward move tests the previous Character support bottom against the top, predicts horizontal overlap at the crossing fraction from the accepted X displacement, and selects the earliest eligible crossing with stable-ID tie-break. Upward, underside, and lateral approaches produce no one-way ceiling or wall. A tiny deterministic support tolerance preserves grounded contact at zero Y and clears it on walk-off. Solid neighbors remain walls and authored Body velocity is retained.

Scale remains local to sparse candidates. A warmed 10,240-cell map (2,150 one-way cells) queried 49 coordinate slots for one Character and 4,900 for 100 Characters, not all authored cells; no per-cell scene objects are created. Measured medians were 0.4141 ms for one Character and 20.3377 ms for the aggregate 100. A 100-scene-platform stack took 0.9944 ms median for one Character. The 500,000-case crossing fuzz and 100,000-case transformed Tile-query comparison both passed across 20 seeds; exact proof JSON is under `qualification/phase-046/`.

This is support-surface behavior, not half a solid Box. It adds no gravity, input, jump, drop-through command, Dynamic Body, Circle one-way, slope/step behavior, moving-platform carry, Layers/Masks, collision-event lifecycle, or per-Tile scene objects. Phase 047/048 and a future drop-through seam are documented separately; Phase 047 is not implemented here.

Qualification evidence is in `PHASE-046-REPORT.md` and `qualification/phase-046/`.
